# Página Web CFL 401

Sitio web oficial / proyecto para el **Centro de Formación Laboral N° 401**. Este repositorio contiene el código fuente y los recursos del desarrollo.

---

## 🚀 Tecnologías utilizadas

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Estilos y diseño responsivo.
* **JavaScript:** Interactividad y lógica (opcional).
